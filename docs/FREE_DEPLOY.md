# Free hosting — LoveGiftCake static frontend

No build step, no bill. The `apps/web/*.html` files run anywhere.

## Option A: Vercel Free (recommended)
1. https://vercel.com → Sign in with GitHub → Add New Project → import `Oluwa-Tayomi/LoveGiftCake`.
2. Framework: Other. Root: `apps/web`. No build command. Output: `.`.
3. Deploy. Every push auto-deploys.

## Option B: Cloudflare Pages Free
1. https://pages.cloudflare.com → Connect GitHub → `LoveGiftCake` → root `apps/web`, no build.
2. Deploy. Free SSL + global CDN.
